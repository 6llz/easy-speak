# 代码规范与安全审查

审查日期：2026-10-18。范围为当前本地源码、锁文件、构建配置、文件导入、持久化、模型请求及本机代理。没有执行公网渗透、第三方供应商攻击或真实手机安装测试；不是安全认证，不能保证系统绝不会被攻击。

## 结论

适合继续推进个人手机测试；**尚未具备公网共享后端或可直接安装的 Android 工程**。当前优先使用安装后填写个人 Key 的直连方式，见 [测试与部署交接](../DEPLOYMENT.md)。不能把开发代理直接搬到公网作为生产服务。

规范的主要要求已有落实：TypeScript strict、组件 / Hook / 模块分层、明确的命名、中文资源管理注释、独立取消与版本隔离、结构校验、密钥与偏好分离。原项目没有提供公司既有规范，因此本报告只针对 CONTRIBUTING.md 的项目基线。

旧本地数据中的未知字段在读取时不会进入 App 视图；相应数据重新保存后才会重写为白名单格式。本轮没有批量删除用户存储，也不能撤回此前自行导出的内容。

## 重复实现与规范整理

- 设置读 / 写共用 normalizePreferences，历史与收藏统一规范化及保存入口，不在组件直接保存原始记录。
- SettingsDialog 与 VoicePicker 共用 useBrowserVoices，统一语言过滤、订阅与卸载清理。
- 删除未使用的旧响应类型、静态教练提示别名；把未知异常的直接 Error 断言改为运行时检查与恢复提示。
- Word 容器安全检查独立成模块，避免文件导入入口继续膨胀；新增资源管理入口有说明职责和边界的注释。
- `.openai` 与日志加入忽略列表，避免调试输出被误提交。

保留问题：usePractice、App、SettingsDialog 和 PracticeScreen 仍偏大，后续应按请求任务、会话记录和媒体控制逐步拆分。当前没有证据表明全面重写状态机会更安全，本轮优先减少可确认的重复与风险。

## 已检查的边界

- 自有页面没有发现原始 HTML 注入、eval、动态 Function 或 shell 执行入口；模型文本与导入材料按文本呈现。
- 远程模型接口要求 HTTPS；拒绝 URL 用户名、密码、查询串、锚点与重定向。个人直连的 Key 只用于供应商请求与当前会话存储，不进入长期偏好。
- 本机代理固定上游及路由，校验回环连接、Host、Origin、客户端标记和请求类型，不接受任意目标 URL。供应商错误正文不透传。
- 语音、摄像头、异步请求有暂停 / 挂断 / 后台取消及迟到结果隔离。相机只本机预览；ASR 会把当前录音发送给供应商，不能描述为“语音始终不出设备”。
- 本地 Vite 开发 / 预览响应增加 nosniff、禁止嵌入、无 Referrer 和同源媒体权限策略。它们不会自动成为未来云服务器或 Android WebView 的安全配置。
- 对 91 个源码、测试、说明及公开资源文件做当前已配置服务端凭据的精确匹配扫描，未命中；生产构建也通过构建门禁。只检查已知明文，不能宣称能识别所有编码、未知凭据或原生安装包内容。

## 依赖扫描

使用正常 TLS 校验和系统受信任证书执行 npm audit，2026-10-18 结果：0 严重、0 高危、3 项中危关联告警。关联路径为 Mammoth 的命令行依赖 `argparse → sprintf-js`，对应同一 sprintf-js 格式精度导致的拒绝服务公告。[漏洞公告](https://github.com/advisories/GHSA-hp3w-g68c-fv3c)

应用使用 `mammoth/mammoth.browser.js`，没有命令行调用；核对该浏览器 bundle，未发现 argparse / sprintf-js 相关模块标识。告警仍保留在锁文件扫描中，不能称为“依赖零漏洞”。npm 给出的自动修复是降到旧的 Mammoth 0.3.29，本轮未强制采用这一大幅降级；需要持续跟踪上游及重新评估运行路径。

## 仍需处理的风险

1. **公网共享服务**：现有代理没有用户身份、按用户配额、账单保护或生产进程入口。没有这些能力时不可开放给公网。
2. **个人 Key 的设备风险**：会话存储不是系统安全保险箱，同源脚本或受控制的设备可读取；个人测试采用安装后输入，未来持久保存需系统安全存储。此前通过聊天传递过的真实凭据应在正式使用前轮换，不能通过修改代码撤回已有副本。
3. **解析器与资源消耗**：文件大小和展开大小限制不等于通用文件沙箱；PDF / 图片解码与 Word XML 仍需维护依赖并做真机资源测试，不宜把客户端导入功能当作匿名批量文件处理服务。DOCX 新增 raw deflate 能力要求，旧 WebView 不支持时明确拒绝并建议 TXT。
4. **提示注入**：参考材料与训练要求已分隔，模型没有系统命令 / 本地文件工具，但提示词本身不保证模型始终遵循教学要求或输出事实正确。
5. **原生包装**：必须单独验证权限、导航、跨域、证书校验、后台恢复和 APK 凭据扫描。当前 Web 自动测试不能证明这些已经完成。

## 验证入口

执行 `npm run format:check`、`npm run lint`、`npm test`、`npm run build`。新增测试覆盖未知字段、ZIP 元数据伪造、原始展开大小、压缩方式、慢请求、并发与构建泄漏；最新数量及真实环境限制以 [验证记录](./verification.md) 为准。
