# 功能说明与验收标准

## 项目名称与摄像头

项目名称为「轻松说」。页面标题、学习中心、默认语伴称呼和导出名称已同步；具名音色与历史发言称呼保持各自名字。原目录、存储键与本机协议保留兼容。

摄像头仅本机预览，界面明确提示 AI 看不到画面。视频理解暂不实现；自定义训练中主动导入图片的功能独立保留。权限见 [设备权限](./permissions.md)，非商用许可和源码分享见 [发布准备](./source-release.md)。

## 音色快捷切换

音色统一收在对话页右上角设置，默认打开“语伴音色”。十二个 MiniMax 预设分别有虚拟名字、声音特点与适用场景，支持独立试听、即时选用、设备声音与自定义 ID。对话页不再单独放音色按钮。打开设置暂停媒体但保留正在生成的主回复与两个教练，选择后下次朗读生效，不重建会话。规格和验收见 [音色切换](./voices.md)。

对话页称呼、思考 / 朗读状态、重听按钮以及新回复的角色名字跟随所选预设；不再固定为 Alex。设备或未知自定义音色使用轻松说。已有消息记录保留发言时的称呼，旧历史没有名字时显示“语伴”。

## 加载与恢复

首屏只加载核心对话；学习中心、设置、历史和收藏在首次打开时加载相应模块。加载中保留关闭 / 返回入口，失败后可原位重试，避免整页空白；原来的暂停与结束意图继续保留。主回复失败后重试仍属同轮发言，尚未完成的点评继续更新；同一教练的重复请求取消旧任务，不干扰另一面板。

## 学习中心扩展

学习中心保留课程、对话、复习、我的四项导航；挑战已移除。四单元十二节课程、按语言分组的复习、自动错题、昵称和每日目标已实现；对话增加隐藏字幕、按需翻译、整句收藏及不推进聊天的独立重练。规则、数据和验收见 [课程、复习与个人成长](./learning.md)。

## 自定义训练

在顶部场景选择弹窗添加“自定义训练”，不占学习导航。一个自由输入框描述训练要求，可粘贴材料或导入文本、PDF、Word、图片；没有分类或固定角色表单。导入先预览并采用，再用当前模型和语言开始；支持显式保存、复用、编辑和删除最多二十个模板。图片选择时由当前视觉模型读取，文档在本机提取，原文件不持久化。规格、限制和验证见 [自定义训练](./custom-training.md)。

## 1. 口语练习室

**用户目标**：像与熟人聊天一样练习所选语言，不面对通话中心式界面。

- 移动 App 单屏布局：顶部为菜单、场景选择与设置，不显示桌面侧栏、首页大标题或统计卡片。
- 上部显示当前音色对应的语伴名字、最近用户发言与当前 AI 回复。完整聊天记录、表达收藏与历史通过左上角菜单进入。
- 中间固定上下两个辅导对话框：上区为灵感教练，下区为表达教练。两区各自滚动和更新，展开例句不会挤走下区。
- 底部为摄像头、文字输入、暂停 / 继续、红色结束按钮，不保留“点击说话”手动麦克风入口。
- 进入页面即尝试自动轮流说话，不设置独立的“开始陪练”按钮。开场结束后等待 400ms 再开启识别；停说后发送，AI 回复播放完再继续聆听。
- 首次访问仍受浏览器麦克风权限与音频自动播放政策限制。权限或识别失败时提供可恢复提示与继续入口，不能保证无用户交互即可播放声音或获得麦克风；用户可以直接切换文字输入。
- 自动朗读开启时尝试播放开场；如果浏览器 2.5 秒内未启动播放，恢复并提示，避免一直停留在“播放中”。自动朗读关闭时直接进入聆听准备状态。
- 暂停后通过底部原有的“继续”控制恢复当前对话；结束后不会自行重启，点击同一“继续”控制则开启新对话。菜单“开启新对话”和场景切换也会创建新会话并自动进入对话。
- 状态为待说话、录音中、转写中、思考中、播放中。转写时暂停开麦与听读入口，避免覆盖尚未完成的发言；录音与语音播放不可同时进行。
- 语音播放时可跳过声音，文字生成和两个教练的请求继续完成；若回复仍在生成，不会立即开启录音。待说话或正在聆听时可重听当前助手发言、例句或改进表达；先停止识别并保留已识别草稿，再播放声音，独立辅导请求继续。
- Alt + M 在有效的自动陪练会话中开启或结束录音；弹窗、文字模式、暂停或结束时不启动录音。
- 自动朗读、语速、声音、练习水平、两种交流语言及停说后自动发送均可配置。
- 单次提交内容最多 3000 字符。转写或其他输入超过限制时停止发送并保留原文，提示用户精简，不截掉后半句后直接提交。

**验收**：发送后只能出现一条用户消息和一个助手回复位置；主回复请求中禁止再次发送或录音。结束播放后恢复可说话状态；播放异常可恢复。切换场景或会话后，不接收旧请求结果。

## 2. 灵感教练：接下来怎么说

**触发**：主陪练新一轮回复完成后刷新。

**内容**：简短中文思路、三个实用英文词组及中文解释；用户可按需展开完整示例、听读、放入输入框修改后发送。每个词组可收藏。听读与“试着用这句”在待说话或聆听时均可使用，结束会话、弹层打开或主回复尚待续接时不可用。

**边界**：只提示如何回应当前话题，不点评用户旧话。请求失败保留已有提示，并在自身面板显示重试入口。不同轮次的提示有版本隔离。

使用例句会切换到文字输入；已有用户草稿时保留原文并提示先发送或放弃，不直接覆盖。听例句不会发送例句，也不会清空草稿；播放结束后，有草稿则等待确认，无草稿且符合自动陪练条件才继续聆听。

**验收**：该面板更新不清空、覆盖或搬动点评区域；示例不会点击即发送。

## 3. 表达教练：刚才说得怎么样

**触发**：用户一句话发送后立即开始，与主陪练请求并行。

**内容**：肯定具体亮点；必要时给出原句片段、自然表达和中文解释。不凭文字转写推断口音、发音或真实流利度，不生成未经测量的分数。

**边界**：只点评最新用户发言。请求失败保留已有点评并提供重试；旧轮次结果不得覆盖当前轮次。

重听改进表达只暂停麦克风并播放选定内容，不取消尚未完成的辅导请求。语音与转写仍按半双工规则轮流进行。

**验收**：AI 回复不进入点评对象；评语不会阻塞下一条主陪练回复。

## 4. 场景与难度

预置四个场景：日常随心聊、职场自信说、旅行途中聊、聊点有意思的。每个场景有独立角色提示；默认组合提供英语开场、中文译文和初始词组，其他组合由模型生成相应语言的开场与提示。切换会保存已有用户发言的会话，再重置对话和辅导区。

练习水平支持 A1 / A2 / B1 / B2 / C1，作为难度参考，传入主陪练和灵感教练提示词。真实模型在该水平下调整表达难度；示范模式不模拟完整的难度自适应。

## 5. 供应商与模型

支持 MiniMax、DeepSeek、OpenAI、通义千问和自定义 Chat Completions 兼容接口。字段包括 Base URL、API Key、对话模型、表达提示模型、说后点评模型。辅导模型为空时复用主模型。

MiniMax 可使用本机服务端保存的密钥，页面只获取连接状态；首次运行自动连接，明确保存过的其他供应商选择保持不变。在设置中可以切换直接填写密钥或本机配置，语音设置独立选择 MiniMax 或浏览器。MiniMax 默认主模型为 `MiniMax-M3`，关闭该模型思考并分离推理字段，正文才进入显示与朗读。

连接测试只测试主模型，界面明确显示辅导模型在实际使用时校验。保存配置不等于供应商连接已通过。无密钥时明确标记为“示范体验”，使用本地有限规则，不冒充真实 AI。真实调用失败时不会悄悄降级为示范。

## 6. 表达收藏与复习

短语按原文及语言组合去重，本地最多 500 项。支持表达与释义搜索、取消收藏、按原练习语言听读、逐卡复习和导出。复习卡先展示熟悉语言释义，再显示练习语言答案；旧收藏按中文辅助英语迁移。

## 7. 练习记录与统计

成功完成用户与助手的一轮对话后，自动保存当前会话快照。切换话题也会保存。同一会话按 ID 更新原记录，不因重复保存增加相同记录。记录最多 100 次，支持搜索内容、查看全文、导出和经确认后删除。

统计来自本机真实记录：练习次数、前台练习时间、按练习语言分词器近似统计的用户表达词数，在记录弹层查看。时间是会话未暂停时的近似前台练习时长，不代表实际语音发声时长；暂停、结束或取消时停止计时。不预填虚构历史。

当前页面未完成的录音不持久化，浏览器音频不保存；关闭页面前尚未完成的消息不保证恢复。持久化受浏览器存储额度、清理策略和隐私模式影响。

## 8. 降级与可访问性

- 识别 API 不支持、麦克风被拒绝、设备不可用、识别网络失败均有提示，文字输入可继续使用。
- 打开弹层、手动暂停或将页面切到后台会暂停录音与播放。主回复已完成时，两个独立教练仍可完成当前请求并更新各自面板；主回复未完成时取消本轮请求并保留续接信息。只有原本活动的会话在关闭弹层或返回前台后自动恢复，手动暂停和结束不会被覆盖，识别错误仍需用户继续。
- 主回复生成途中被挂起时，保留已经发送的用户消息，恢复时重新生成该轮回复，不重复追加用户消息，也不把被取消的半截回复当作完整上下文。已完成回复或手动选中的例句、改进表达被暂停时，恢复后从同一段内容的开头重听。
- 识别过程中切换文字或暂停时保留已识别草稿，提供确认发送与放弃入口；不把未确认草稿自动发出，也不在后台重新录音。
- 识别正常结束但没有有效文字时，也暂停自动聆听并提示用户继续，避免麦克风在静默时反复重启。
- 弹窗支持焦点限制、Escape 退出、关闭后恢复焦点。
- 主要按钮有可读名称，状态用文字及图标表达。
- 响应式适配桌面与手机，始终使用同一单屏陪练结构；遵循系统“减少动态效果”设置。

浏览器 / 真机 / 真实供应商验证情况以 [验证记录](./verification.md) 为准。

设置、历史消息与收藏按字段白名单读写；保存失败如实提示。文件导入对 DOCX 增加实际展开大小检查，不仅依赖 ZIP 声明；旧设备不支持安全解压时提示改用 TXT。代码审查、构建检查与个人手机直连方案见 [安全审查](./security-review.md) 和 [部署交接](../DEPLOYMENT.md)。

### MiniMax 语音

MiniMax 语音识别通过麦克风采集当前片段，持续发声后默认约三秒静音时停止录音并立即释放轨道；在“语音与偏好”可选二 / 三 / 五秒，继续发声重新计时。初始十秒无有效发声时暂停，单段最长六十秒。浏览器录音在内存解码为单声道 PCM16 WAV，再提交 `asr-1.0`，转写完成后按自动发送偏好进入对话。没有逐字转写预览；转写中明确显示状态。失败提供恢复提示，不反复自动请求权限。

浏览器识别模式同样保留停顿窗口，尝试将底层提前结束的片段续接为一轮，不再一收到原生结束事件就提交；支持程度取决于浏览器。两个教练和重练遇到格式 / 截断失败最多自动恢复一次，新一轮不会显示上一句旧点评。具体边界见 [停顿与点评恢复](./conversation-timing.md)。

朗读使用 `speech-2.8-turbo` 与可编辑音色 ID，语言参数跟随练习语言，按句合成、顺序播放，播放期间最多预取下一句；无标点时在文字完成后合成剩余内容。暂停、挂断、后台或切换场景取消相应录音、转写与播放；旧权限或网络结果不能恢复已取消的会话。音频只留在内存，不录制保存文件，摄像头内容不提交供应商。该流程由语音识别、文字模型和语音合成串联，不是原生端到端语音对语音接口。

“测试语音连接”只验证合成接口返回音频，不代表麦克风、浏览器播放政策或真实设备体验已验收。真实语音不静默降级为其他声音；用户可手动改选设备声音、浏览器识别或打字。

MiniMax 同一回复复用一个播放器，句间切换音源时不反复销毁播放器，音量保持正常值；完成或取消仍释放资源。未添加淡入、增益放大或等待延迟。电脑蓝牙耳机开头音量偏小的系统设置与对照步骤见 [播放排查](./audio-playback.md)，此项优化不代表真机听感已修复。

## 9. 摄像头与结束陪练

摄像头通过 `getUserMedia` 请求前置镜头，开启后显示带“仅本机预览”标记的小窗；不同时请求摄像头音轨，不向模型发送视频帧，不录制、不保存视频。再次点击关闭；设备不存在、占用或权限拒绝时显示提示，其他功能仍可使用。页面切到后台、离开页面或结束会话会释放镜头轨道；返回前台不会自动重开摄像头。

红色结束按钮会取消所有模型请求、识别和朗读，停止计时，关闭摄像头轨道，并保存已有用户发言的练习记录。结束后自动识别不能重启。即使摄像头权限请求在结束之后才返回，返回的媒体流也必须立即释放。组件卸载也执行摄像头清理。

识别网络失败、未检测到语音等异常会暂停自动陪练，避免无限重试权限或识别请求；用户可点击“继续”或切换文字。打开弹层或切换文字时，不启动新一轮自动识别。结束后若要再次练习，通过底部同一个“继续”控制或菜单开启新对话；旧会话的文字记录继续保留。

## 10. 主题配色

左上角菜单的“主题配色”与设置中的同名标签提供四种选择：暮色紫（默认）、海盐蓝、森林绿、奶油白（浅色）。点击色卡立即应用于陪练页面、辅导框、按钮与弹层，无需保存模型配置；保持同一套移动 App 布局与交互。

主题偏好保存在当前浏览器，刷新后恢复，不随场景切换、暂停或结束会话而重置。同源其他标签页修改主题时同步更新；切换主题本身不保存或改动模型配置。存储失败时当前页面仍使用所选主题，并提示未能持久保存。

**验收**：选择主题后当前页面立即更新；关闭选项再打开时选中状态正确；刷新页面保持所选配色；存储值缺失或不受支持时回退默认主题。状态文字与图标在各主题中可辨识，错误与结束操作保留明确的语义颜色。

## 11. 两种交流语言

点击主屏场景下方的语言组合，分别选择“我熟悉的语言”和“想练习的语言”。可互换方向，或通过“其他语言”填写 BCP-47 代码；阻止相同组合和无效代码。主陪练主要使用练习语言，接受两种语言和混合输入；两个教练用熟悉语言解释，例句、词组及改进表达使用练习语言。

切换后保存原记录、取消旧媒体与请求、清空新会话辅导，并生成相应开场。旧请求不能覆盖新语言内容。语言偏好刷新保留；收藏及历史保留各自语言，重听使用收藏原语言。默认中文辅助英语仍可本地示范，其他组合无密钥时明确提示连接模型，不继续输出英语示范。

浏览器识别跟随练习语言；MiniMax 在两种语言均支持时自动识别混合表达，不支持的语音功能提前提示，文字交流仍可用。语言选择不代表所有模型和音色支持所有语言，详见 [语言功能说明](./languages.md)。

**验收**：中文 / 日语及法语 / 日语互换后，主回复、提示、点评和语音请求随之更新；保存和刷新后组合保留；新旧记录的语言互不混淆；未知语言代码不能注入提示词；非拉丁文本按自身方向显示。
