# 课程、复习与个人成长

参考用户提供的 App 截图，补充学习路径、对话辅助、错题回顾、复习计划与成长反馈。默认打开原有陪练屏，底部“学习中心”或菜单“课程、复习与成长”进入学习中心。学习中心保留课程、对话、复习、我的四项导航；挑战已移除。进入对话后使用原来的摄像头、文字、暂停和挂断控制。自定义训练位于顶部场景弹窗，使用自由文字与附件，不占导航。

## 课程规则

四个单元分别为“从一句话开始”“带着语言去旅行”“在工作中表达自己”“把故事讲得更生动”。课程声明交际目标、建议级别、角色提示和默认中英开场；其他语言组合由模型生成对应语言开场，角色任务不变。建议级别仅作选课参考，对话难度继续使用用户的设置。

每节课需要在同一次真实模型会话中完成至少三轮用户发言与助手回答，才标为“已练习”。未回复的发言、空白占位、示范会话和独立重练不累计课程完成度。该标记代表练过，不是对三个交际目标的自动评估，也不等于能力达标。达到轮数后可继续聊，不强制挂断。下一节推荐为当前语言组合内第一节尚未完成的课程。

课程模式复用 `createLessonScene` 和 `usePractice`，不建立另一套录音或供应商请求流程。离开对话进入学习中心时，挂起会话、保存已有记录并释放镜头；返回时保留原来的手动暂停和挂断意图。原本活动的会话才自动恢复，未完成的主回复按原用户发言续接。

## 独立重练与翻译

“再试一次”进入独立重练状态，使用当前练习语言的语音识别和当前点评模型。新的输入只提交给点评角色，不追加到主消息列表、不刷新上区灵感、不记成课程轮次，也不新增错题；原下区点评保留。结果显示后停止自动开麦，用户可再练一遍或返回聊天。无密钥时明确沿用示范点评，非默认组合仍需模型。

重练失败保留本次文字，用户可重试或退出。已有未发送草稿时拒绝进入，避免丢失原话。取消重练、挂断和新会话会中止对应请求，晚到结果不可写回。

翻译只在点击时调用，使用辅助语言与表达提示模型（未指定时复用主模型）。已有译文直接显示，同一条请求中的重复点击不再次联网。翻译不自动朗读、不改写原文；切换会话或进入下一轮后旧翻译不得覆盖当前消息。无密钥的示范仅有预置开场译文。

## 错题与复习规则

真实点评同时包含非空、不同的原句和改进表达时，按用户消息 ID 记入错题。重试点评覆盖同一条记录，不重复新增；若最新点评认为无需纠错，移除该消息原有的过期错题。自然表达无需纠错时不创建错题，示范点评不进入待复习列表。最多保存三百条改进记录。

复习项由收藏与错题实时派生，按熟悉语言和练习语言共同隔离。旧收藏与记录默认迁移为中文辅助英语。词语 / 表达目前按长度启发式分组，并非词性识别或习语语料库。

| 自评     | 下次复习                           | 连续记住次数 |
| -------- | ---------------------------------- | ------------ |
| 再练练   | 十分钟后                           | 归零         |
| 有点印象 | 一天后                             | 加一         |
| 记住了   | 首次三天，以后逐次翻倍，最多三十天 | 加一         |

先展示释义或待改进原句，揭晓后才能自评。组内使用固定快照，已完成后展示总结，不无限循环最后一项。自评是记忆安排，不能当成发音、流利度或 CEFR 测评结果。同一表达一天内重复复习只计一次学习事件。

## 成长统计

统计只计算当前语言组合下的真实会话；新示范会话明确保存 `isDemo`。旧版本未记录示范来源，兼容时按历史记录处理，因此旧数据无法追溯区分示范与真实调用。

- 已完成轮次：非空用户消息后面紧接非空助手回答。
- 时长：会话活动时的近似前台秒数，按分钟向下取整，不是实际发声时长。
- 每日目标：五、十、十五或二十分钟；默认十分钟。
- 连续天数：按设备本地日历计算；今天还没练时，连续记录可延续至昨天。
- 本周日历：按当前语言组合的完成轮次标出练习日。

挑战、月目标与段位页面已移除。底层原有的周 / 月派生统计暂留以保持已有数据和测试兼容，不再提供挑战入口，不当作语言水平评估。

统计由现存快照计算；同一会话按 ID 去重，删除历史或超过一百条记录上限时相应累计值会变化。时间归属记录最后保存的日期，跨午夜长会话没有逐分钟活动账本。复习事件最多保留一千条，超过后删除最早事件。暂无服务端永久学习账本、账号、跨设备同步或真人联赛。

## 数据与接口

新增 `morrow:corrections`、`morrow:learning` 两个本地键。前者为语言组合与原句 / 改进 / 原因，后者为昵称、目标、自评排期与有限复习事件。均不含密钥或录音；浏览器存储失败时有提示。

错题写入使用逐字段白名单；传入完整模型设置也只保存两种语言代码。启动时和读取时清理旧版曾误展开的额外字段并回写，保存失败则提示；已经规范的记录不重复写入。清洗返回的内存对象同样不包含凭据或供应商设置。此迁移不能撤回此前已被其他程序读取或用户自行导出的旧数据。

无新增后端路由。翻译和重练复用既有 Chat Completions 请求；保留三十五秒超时、取消、正文长度限制与本机凭据边界。翻译和重练会产生选定供应商的实际调用。

## 验收

1. 从对话进入学习中心，确认停止开麦和播放；已开启的镜头释放。
2. 任意选择一节课，查看三项交际目标，进入后看到课程轮数和两个固定辅导区。
3. 真实完成三轮后返回课程，完成标记和下一节推荐更新；示范对话不标完成。
4. 隐藏字幕后能重听；翻译实际回复后切换消息，确认译文不串句。
5. 点评中“再试一次”，提交后主聊天消息数量不变；退出后能继续原话题。
6. 错题进入复习，揭晓后自评；完成后出现总结，刷新仍保留排期。
7. 切换语言组合，课程、复习和统计随组合隔离；收藏听读使用其原语言。
8. 四项导航没有挑战或自定义训练替代项；顶部场景弹窗可以打开自由训练，个人统计空数据为零。
9. 手机检查长句、软键盘、字幕工具栏、导航安全区和四种主题；真实设备结果单独记录。
