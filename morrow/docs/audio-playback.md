# 蓝牙耳机开头声音偏小

## 现象与排查结论

电脑连接蓝牙耳机时，用户反馈回复开头几个音节偏小，随后恢复。项目没有加入淡入、渐强或动态增益；MiniMax 合成音量为 `vol: 1`，客户端播放器使用正常音量 `volume: 1`。这不表示合成音频本身的响度已经经过测量，也不能仅凭代码断定硬件原因。

优先排查两个系统行为：

- 经典蓝牙在媒体播放 A2DP 与通话 HFP 之间切换。Windows 会按耳机麦克风是否启用自动选择模式，录音结束与播放开始会改变模式；具体转换听感因设备而异。[Microsoft 蓝牙音频说明](https://learn.microsoft.com/en-us/windows-hardware/drivers/bluetooth/bluetooth-classic-audio)
- Windows 通信活动可能压低其他音频，通信结束后恢复。这是系统音量衰减策略，网页播放器音量保持 1 时也可能发生。[Microsoft 通信音量说明](https://learn.microsoft.com/en-us/windows/win32/coreaudio/stream-attenuation)

用户尚未完成对比实验，以上均为待验证原因，不能宣称已经确认根因。蓝牙 LE Audio 和不同驱动行为不能一概按经典蓝牙描述处理。

## 电脑上的对比步骤

1. 在 Windows 的声音设置中，将输入切换为电脑内置或外接麦克风，输出继续选择蓝牙耳机；浏览器麦克风设置也选择同一输入，刷新页面后再试。若没有独立麦克风，可以先用扬声器或有线耳机做对照。如果改用独立麦克风后恢复，说明问题与耳机麦克风或音频模式切换有关。
2. 按 Win + R，输入 `mmsys.cpl`，在声音窗口的“通信”页选择“不执行任何操作”，应用后再试。此项用于验证系统通信音量衰减，只改变衰减策略，不会禁止蓝牙模式切换。应用不会代替用户修改全局声音设置。
3. 在页面暂停自动陪练，再点回复的重听或设置里的音色试听。分别比较蓝牙、扬声器或有线耳机的开头；同时确认其他通话软件没有占用耳机麦克风。如果所有输出设备都有相同现象，需要继续检查对应音色与实际合成音频，不能继续只归因于蓝牙。

Windows 10 的设备列表可能分开显示 Stereo 与 Hands-Free；如果存在两项，独立麦克风搭配 Stereo 输出适合这一步对照。Windows 11 可能统一显示一个设备，不要求一定找到两个名称。

## 播放队列调整

`MiniMaxVoiceQueue` 原先每句话新建和销毁 `Audio`。现改为同一回复复用一个播放器，切换下一句只换音源，不在句间清空并重载元素；最多预取下一句，首句仍无需等全文合成。音量显式设为正常值，不增加额外等待或音量放大。设备声音仍由浏览器语音合成管理。

每个片段独立递增播放版本，旧片段的结束、报错、开始事件和迟到的 `play()` 拒绝不会操作下一句。全部播放完成、取消、后台挂起或失败时仍清理播放器、定时器与内存 Blob URL；新音源安装后撤销上一个 URL。

该调整减少重复创建播放器，不保证浏览器底层音频流始终保持，也不能控制系统蓝牙模式、耳机固件或通信衰减。没有用持续开麦、隐藏保活声音或全局系统设置来掩盖问题。

## 验证边界

自动测试覆盖同一播放器顺序播句、一次预取、旧事件与迟到播放拒绝隔离、合成等待期间取消、正常完成和播放拒绝时的资源清理。模拟播放器无法测量耳机实际声压、系统模式切换或 MiniMax 音频的开头响度，需按上述步骤做设备听感验收。
