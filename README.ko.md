# EasySpeak · 轻松说

[简体中文](./README.md) · [English](./README.en.md) · [日本語](./README.ja.md) · **한국어** · [Español](./README.es.md) · [Français](./README.fr.md) · [Deutsch](./README.de.md)

</div>

EasySpeak(轻松说)는 성인을 위한 모바일 중심 AI 회화 연습 Web App입니다. 주 대화 상대와 별도로 중앙의 두 코치 영역이 독립적으로 작동합니다. 위쪽은 다음에 할 말을 돕고, 아래쪽은 방금 한 발화만 검토합니다.

> **[Apache License 2.0](./LICENSE)으로 공개합니다. 조건을 지키면 상업적 이용, 수정, 배포가 가능합니다.** 필요한 라이선스와 저작권·기여 표시를 유지하고 변경 사항을 표시해야 합니다. 외부 구성 요소에는 각자의 라이선스가 적용됩니다.

위의 언어 링크를 눌러 README를 전환하세요. 상세 기술 문서는 현재 주로 중국어로 제공됩니다.

## 주요 기능

- **자연스러운 음성 대화:** AI 발화가 끝나면 마이크를 여는 반이중 방식입니다. 음성 인식, 스트리밍 응답, 음성 합성을 연결하며 텍스트 입력도 지원합니다.
- **독립 코치 두 명:** 위쪽에는 아이디어, 표현, 펼쳐 보는 예문을 표시하고, 아래쪽은 최신 사용자 발화만 검토합니다. 각 영역을 따로 갱신하거나 재시도할 수 있습니다.
- **언어와 수준 선택:** 익숙한 언어와 연습 언어를 선택·교환하고 언어 코드를 입력할 수 있습니다. A1–C1을 난이도 참고로 사용합니다.
- **맞춤 훈련:** 원하는 상황을 자유롭게 입력하고 기사, 이력서, 단어 등 자료를 추가합니다. 가져온 내용을 확인한 뒤 사용하고 템플릿으로 저장할 수 있습니다.
- **파일과 이미지:** TXT, Markdown, CSV, 텍스트 PDF, DOCX, PNG, JPG, WebP를 지원합니다. 문서는 기기에서 텍스트를 추출하고 이미지는 시각 모델로 읽습니다.
- **여러 공급자:** MiniMax, DeepSeek, OpenAI, Qwen, Chat Completions 호환 API를 지원합니다. 코치 모델 ID는 별도로 지정할 수 있지만 대화 공급자와 키는 공통입니다.
- **음성과 대기 시간:** 이름이 있는 MiniMax 음성 12개, 미리 듣기, 기기 음성, 사용자 음성 ID와 2 / 3 / 5초의 발화 종료 대기를 제공합니다.
- **학습과 복습:** 대화 과제 12개, 표현 저장, 자동 교정 노트, 간격 복습, 개인 목표, 언어 조합별 통계를 지원합니다. 테마 4개, 자막 숨기기, 요청 시 번역, 교정 후 재연습, 텍스트 내보내기도 있습니다.

**카메라는 기기 내 미리 보기 전용이며 AI에 화면을 보내지 않습니다.** 실시간 영상 이해는 구현되지 않았습니다. 맞춤 훈련에서 직접 선택한 이미지를 읽는 기능은 별도의 업로드 동작입니다.

## 시작하기

Node.js 22.13 이상(24 권장), npm, 최신 브라우저가 필요합니다. 브라우저 음성 인식에는 Chrome / Edge를 권장하며 지원 언어는 공급자에 따라 다릅니다.

저장소 루트에서 실행합니다.

```sh
cd easy-speak
npm ci --cache .npm-cache
npm run dev
```

보통 <http://127.0.0.1:5173/> 를 엽니다.

1. 오른쪽 위 설정에서 공급자를 선택하고 Base URL, 개인 API 키, 모델 ID를 입력합니다.
2. 음성 환경설정에서 브라우저 인식 / 기기 음성 또는 MiniMax ASR / TTS를 설정합니다.
3. 마이크를 허용한 뒤 상대의 발화가 끝나면 말합니다. 권한이나 재생이 차단되면 안내에 따라 복구하거나 글로 입력합니다.
4. 위쪽에서 언어 조합이나 상황을 바꿉니다. 맞춤 훈련도 상황 선택 안에 있습니다.

키가 없으면 중국어 설명을 사용하는 영어 연습 로컬 데모만 제공됩니다. 다른 언어 조합, 맞춤 훈련, 실제 모델 응답에는 공급자 설정이 필요합니다. 공용 키나 무료 API 할당량은 제공하지 않으며 비용은 본인 계정에 청구됩니다.

### 선택 사항: 로컬 MiniMax 프록시

앱 디렉터리에서 환경설정 예시를 복사합니다.

```sh
# macOS / Linux
cp .env.example .env.local
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env.local
```

.env.local의 MINIMAX_API_KEY를 설정하고 개발 서버를 다시 시작합니다. 비밀 값에 VITE_ 접두사를 사용하거나 .env.local을 커밋하지 마세요. 브라우저에는 상태와 대체 값만 전달합니다.

프록시는 루프백 연결만 허용하는 로컬 개발용입니다. 정적 호스팅에는 포함되지 않으며 공용 백엔드로 사용할 수 없습니다. [공급자 설정](./easy-speak/docs/providers.md)

Windows에서 의존성 설치 후 저장소 루트에서 백그라운드로 시작할 수 있습니다.

```powershell
.\Start-EasySpeak.ps1
```

정상 서버를 재사용하고 로그는 프로젝트 안에 둡니다. Windows 로그인 시 자동 실행을 설정하지는 않습니다.

## 구조와 개인정보

음성 흐름은 **ASR → 언어 모델 → TTS**입니다. 주 응답과 직전 발화 검토는 병렬로 처리하며, 다음 발화 힌트는 주 응답 완료 후 갱신합니다. 취소와 버전 확인으로 오래된 결과가 새 대화를 덮어쓰지 않도록 합니다.

- 마이크는 음성 입력에 필요합니다. MiniMax ASR에는 현재 녹음을 보내며 브라우저 인식의 처리는 해당 브라우저·서비스에 따릅니다.
- 카메라는 선택 사항인 로컬 미리 보기이며 녹화나 화면 업로드를 하지 않습니다. 닫기, 대화 종료, 백그라운드 전환 시 해제합니다.
- 직접 선택한 파일만 읽습니다. 문서는 로컬에서 처리하고 이미지 이해 시 압축 이미지를 업로드합니다. 채택한 텍스트 자료는 훈련 시작 시 모델로 보냅니다.
- 직접 연결 키는 현재 탭의 sessionStorage에 두며 기기의 보안 저장소는 아닙니다. 프록시 키는 무시되는 .env.local에 저장하고 장기 설정·내보내기에는 포함하지 않습니다.
- 기록, 저장 표현, 명시적으로 저장한 템플릿은 현재 브라우저에만 보관합니다. 계정이나 클라우드 동기화가 없으므로 브라우저 데이터를 지우기 전에 내보내세요.

## 개발과 문서

앱은 easy-speak/에 있습니다. src/에 컴포넌트·Hook·기반 모듈, server/에 로컬 프록시와 빌드 검사, tests/와 docs/에 테스트·명세가 있습니다. 기존 브라우저 데이터 키는 호환성을 유지합니다.

앱 디렉터리에서 검사합니다.

```sh
npm run format:check
npm run lint
npm test
npm run build
npm run preview
```

빌드 결과는 easy-speak/dist에 생성되며 preview는 로컬 확인용입니다. 저장소 루트에서 소스 ZIP을 만들 수 있습니다.

```powershell
.\Export-EasySpeak.ps1
```

명시적 목록의 파일만 release/easy-speak-source.zip에 넣고 알려진 키 및 일반적인 비밀 값 형식을 검사합니다. 실제 환경설정, 의존성, 캐시, 로그, 빌드 결과와 브라우저 학습 데이터는 포함하지 않고 업로드도 하지 않습니다.
