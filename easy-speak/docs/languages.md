# 两种交流语言

## 使用与验收

主屏场景按钮下方显示当前“熟悉语言 ↔ 练习语言”。点击后分别选择“我熟悉的语言”和“想练习的语言”，可点“互换语言”交换方向，再点“应用语言”。默认是中文辅助练英语。常用语言列表提供快捷选择；“其他语言”允许填写 BCP-47 代码，例如 `sw-KE`，不把选项列表当作文字模型能力的封闭列表。

主陪练主要使用练习语言，接受两种语言及混合输入；用户求助时可短暂使用熟悉语言。上区的解释、词组释义与下区点评使用熟悉语言，词组、例句和改进表达使用练习语言。界面菜单仍使用中文，本功能不切换整套 UI 的显示语言，也不是双人同声传译模式。

应用新组合时保存已有用户发言的原会话，取消旧请求与媒体，清空新会话的两区内容，并生成相应语言的开场。旧轮次晚到结果不能写入新组合。选择与当前相同的组合直接关闭面板，不重启对话；两端完全相同则要求重新选择。语言偏好刷新后保留。

中文辅助练英语沿用本地示范；其他组合需要真实模型。未连接模型时显示说明并禁止自动开麦，不生成冒充其他语言的英语示范。文字交流能力、表达质量及难度适配取决于所选模型，不宣称任意模型都精通全部语言。

## 契约与持久化

`Settings` 增加 `supportLanguage`、`practiceLanguage`，均为规范化语言代码。`Intl.Locale` 校验并提取 `baseName`；不接受任意自然语言说明或超长内容作为代码。显示名由 `Intl.DisplayNames` 生成，不把用户自定义提示直接拼入系统提示。损坏、缺失或重复的旧偏好安全回退到默认组合。

三个角色通过 `mainPrompt`、`hintPrompt`、`reviewPrompt` 生成各自语言规则。辅导协议保留旧字段 `words[].en` / `words[].zh`：它们分别表示“练习语言表达”和“熟悉语言释义”，不是固定的英语 / 中文约束。`Review.original` 保留原话，`improved` 使用练习语言，解释和类别使用熟悉语言。

会话及收藏增加同名语言字段；旧数据读取时按中文 / 英语迁移。收藏按原文及语言组合去重，跨语言的同形词可分别保存，重听使用该收藏自己的练习语言。历史显示原语言组合。词数使用当前练习语言的 `Intl.Segmenter` 近似统计用户文本，不代表发音、流利度或严格的语言学词数。

## 语音边界

- 浏览器识别的 `lang` 使用练习语言代码；浏览器接口一次选择一种语言，熟悉语言可通过文字输入。识别支持程度取决于设备和服务。
- 设备朗读设置相应 `SpeechSynthesisUtterance.lang`，仅在同语言的音色中选择，不沿用之前显式选中的英语音色。中日文、阿拉伯语及印地语常见句末也可切句；长的无空格语句按分词估算播放时长，避免被误判卡住。
- MiniMax 朗读按练习语言映射 `language_boost`，保留可编辑音色 ID。音色的跨语言效果需实际试听；不自动声明所有音色都具有母语口音。
- MiniMax ASR 在两个基础语言都受支持时省略语言提示，启用混合语言识别；只覆盖练习语言时传其基础代码。未覆盖练习语言时明确提示改用浏览器识别或文字，不伪装为英语识别。
- 本机代理只允许 MiniMax 已记录的 ASR 语言代码或空值，未知值返回 `400 INVALID_LANGUAGE`；不再覆盖成固定 `en`。直接模式的语音接口还须允许 `language` 请求头跨域。
- MiniMax 未覆盖的朗读语言同样明确报错；语言选择面板提前显示对应边界，不暗中改用另一供应商。

语言覆盖依据 [MiniMax ASR 文档](https://platform.minimax.io/docs/api-reference/speech-to-text) 和 [TTS 文档](https://platform.minimax.io/docs/api-reference/speech-t2a-http)。文字语言选择范围与语音供应商支持范围分别处理。

## 验证

自动测试覆盖代码校验与迁移、互换、自定义及重复选择、三个角色提示、音频语言参数、混合识别、非拉丁句末、长句播放、原记录保留与旧请求隔离。另用真实 MiniMax 验证法语辅助日语、日语辅助法语两个方向的三个角色、合成音频与转写。真实麦克风、声音听感和手机视觉验收仍按 [验证记录](./verification.md) 执行。
