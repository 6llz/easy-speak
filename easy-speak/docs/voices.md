# 对话页音色切换

## 使用

点击对话页右上角的设置图标，默认进入“语伴音色”页签。对话页不再单独显示音色按钮。每张卡片展示名字、原始语种、声音特点及适合的聊天场景；点击名字即时选用并保存，面板继续保留，点“完成”回到对话。点击喇叭只试听，不改变当前选择，再次点击可停止。下次自动朗读或手动重听使用新音色，刷新保留偏好。

预设共十二个：英文六个，普通话、日文、法文各两个。按当前练习语言优先排列，其余仍可试听。卡片标注音色的原始语种；实际合成文本和语言参数使用当前练习语言，不会因为换音色而切换交流语言。没有该语种预设时可选择其他音色、设备声音或自定义音色，发音与风格以实际试听为准。

设备声音在同一面板选择，候选由浏览器按当前练习语言加载；保留自动选择项。自定义音色继续在“语音与偏好”设置中填写，当前自定义 ID 不会被预设覆盖；面板提供前往设置的入口。设置页也增加同源的预设下拉框。

## 会话与资源规则

- 语伴称呼跟随预设：例如诺亚使用 Noah，克拉拉使用 Clara；设备与自定义音色用轻松说。主屏、思考 / 朗读状态、重听与帮助文案同步，新主回复的系统提示使用该名字。切换不要求模型主动重新介绍。
- 每条新助手消息保存发出时的 `companionName`，历史和导出不因以后换音色而改名；旧记录缺少名字时显示“语伴”。尚未开聊的课程预置介绍可以更新名字，已有用户对话或生成内容保留原文。
- 打开音色面板后暂停麦克风和当前声音，保留未发送草稿。主回复和两个教练仍可完成，不取消请求或重新生成用户这一轮回答。
- 选音色只更新 `speechProvider` 与相应音色字段，不改变对话供应商、密钥、语速、自动朗读开关、录音服务、场景或交流语言；不新建会话、不清空聊天与辅导内容。
- 切换后使用下次朗读，不自动重播上一条主回复。关闭面板仅恢复原本活动的会话；手动暂停、挂断、草稿和识别错误继续受原门控约束。
- 试听与主陪练共用 `createSpeechQueue`，MiniMax 合成沿用超时、取消、长度与播放看门狗，不新增后端路由。
- 同时只允许一项试听。换音色、停止、选用、关闭、跳转设置、切后台和卸载取消旧请求并释放播放器及 Blob URL；旧结果不能恢复播放或覆盖新状态。
- MiniMax 需要已有语音凭据。未连接时显示明确错误，不把其他对话供应商的密钥发送给 MiniMax，也不静默切换服务。设备声音仍可独立选择。
- 试听文本使用当前练习语言。常见语言有简短示范句，其他语言使用该语言的本地名称；不是翻译或完整教学例句。
- MiniMax 试听会消耗所选语音服务额度；合成音频仅在内存，不写入本地文件或长期缓存。

## 工程结构

`lib/voicePresets.ts` 维护预设、排序、显示名称、试听短句和纯配置变换。`lib/speechQueue.ts` 统一创建实际播放队列。`hooks/useVoicePreview.ts` 独立管理单一试听版本与资源释放。`VoicePicker` 仅展示和响应选择，`App` 负责应用及保存。

`useMediaSession.preserveReplyOnOverlay` 用于设置面板，进入时调用 `suspend({ preserveReply: true })`，主回复与教练可继续完成。`usePractice.updateSpeechSettings` 同步更新后续语音使用的引用，同时停止旧声音，不递增会话或教练请求版本。`SettingsDialog` 在即时选用后只同步草稿的三个朗读字段，保留其他尚未保存的修改，防止以后保存其他设置时恢复旧音色。其他设置仍按“保存设置”生效。持久化继续使用 `morrow:settings` 及会话密钥存储，无新增数据键。

## 验收

1. 点击对话主屏右上角设置，默认显示“语伴音色”，主屏没有独立音色按钮；卡片显示名字、特点和适用场景。
2. 先试听几个音色，确认当前偏好不变；点击名称后选中状态更新，点“完成”返回，新音色用于下一次重听。
3. 正在录音时打开面板，麦克风停止，草稿保留；播放试听期间不得重新录音。
4. 主回复生成中打开面板并切换，主回复和点评继续完成，没有重复用户消息或重新发起主回复。
5. 快速试听 A → B，停止或关面板，确认 A 的迟到合成结果不能恢复声音。
6. 手动暂停或挂断后操作音色，关闭面板仍保持原意图。
7. 切日语、法语、中文等语言，列表优先顺序、试听文字和合成参数跟随变化；刷新保留选定音色。
8. 手机测试面板滚动、喇叭命中范围、自动播放权限、蓝牙和扬声器的实际听感。
9. 选 Noah 再选 Clara，主屏与状态称呼同步；下次发送使用 Clara 的角色提示，旧消息和导出仍保留原称呼。设备 / 自定义音色显示轻松说。
