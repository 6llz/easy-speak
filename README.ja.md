# EasySpeak · 轻松说

[简体中文](./README.md) · [English](./README.en.md) · **日本語** · [한국어](./README.ko.md) · [Español](./README.es.md) · [Français](./README.fr.md) · [Deutsch](./README.de.md)

**友だちと話すように、使いたい言語を練習しましょう。**

</div>

EasySpeak（轻松说）は、成人向けのモバイル優先 AI 会話練習 Web アプリです。メインの会話相手に加えて、中央に独立した二つのコーチ欄があります。上は「次に何を言うか」、下は「直前に話した内容」をサポートします。

## 主な機能

- **自然な音声会話：** AI の発話が終わってからマイクを使う半二重方式。文字起こし、ストリーミング応答、音声再生を順に処理します。文字入力にも対応します。
- **独立した二つのコーチ：** 上欄に会話のヒント、表現、必要に応じた例文。下欄は最新のユーザー発言だけを添削し、それぞれ独立して更新・再試行します。
- **言語と難易度：** 説明に使う言語と練習する言語を選択・交換でき、言語コードも指定可能です。A1–C1 を難易度の目安にします。
- **自由なカスタム練習：** 場面や目的を入力し、記事・履歴書・単語などを追加。取り込み内容を確認してから使い、テンプレートを保存できます。
- **ファイルと画像：** TXT、Markdown、CSV、テキスト PDF、DOCX、PNG、JPG、WebP。文書は端末上でテキスト化し、画像は視覚対応モデルで読み取ります。
- **複数プロバイダー：** MiniMax、DeepSeek、OpenAI、Qwen、Chat Completions 互換 API。コーチごとにモデル ID を選べますが、対話用プロバイダーとキーは共通です。
- **音色と間：** 名前付き MiniMax 音色 12 種類、試聴、端末の音声、独自音色 ID。発話の終了待ちは 2 / 3 / 5 秒から選択します。
- **学習と復習：** 12 の会話課題、表現の保存、自動添削ノート、間隔を空けた復習、目標、言語ペア別の統計。4 テーマ、字幕非表示、必要時の翻訳、添削後の再練習、テキスト書き出しにも対応します。

**カメラは端末内のプレビュー専用で、AI に映像は送られません。** リアルタイム動画理解は未実装です。カスタム練習で自分で選んだ画像の読み取りは、別のアップロード機能です。

## 起動方法

Node.js 22.13 以降（24 推奨）、npm、最新ブラウザーが必要です。ブラウザー音声認識には Chrome / Edge を推奨します。対応言語は選択したサービスによります。

リポジトリのルートで実行します。

```sh
cd easy-speak
npm ci --cache .npm-cache
npm run dev
```

通常は <http://127.0.0.1:5173/> を開きます。

1. 右上の設定からプロバイダーを選び、Base URL、個人の API キー、モデル ID を入力します。
2. 音声設定でブラウザー認識・端末音声、または MiniMax ASR / TTS を選びます。
3. マイクを許可し、相手の発話後に話します。権限や再生が制限された場合は画面の案内に従うか、文字入力を使います。
4. 上部の言語ペアや場面を変更します。カスタム練習は場面選択内にあります。

キー未設定時は、中国語で補助する英語練習のローカルデモのみ使えます。他の言語ペア・カスタム練習・実際の AI 応答には接続設定が必要です。共有キーや無料枠は提供せず、API 利用料は自分のアカウントに発生します。

### 任意：MiniMax のローカルプロキシ

アプリのディレクトリで設定例をコピーします。

```sh
# macOS / Linux
cp .env.example .env.local
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env.local
```

.env.local の MINIMAX_API_KEY を設定してサーバーを再起動します。秘密情報に VITE_ 接頭辞を使わず、.env.local をコミットしないでください。ブラウザーには状態と仮の値だけを渡します。

プロキシはループバック接続のみの開発用です。静的ホスティングには含まれず、公開用バックエンドではありません。[接続仕様](./easy-speak/docs/providers.md)

Windows で依存関係をインストールした後、リポジトリのルートからバックグラウンド起動できます。

```powershell
.\Start-EasySpeak.ps1
```

正常なサーバーを再利用し、ログはプロジェクト内に保存します。OS 起動時の自動起動は設定しません。

## 仕組み・権限・プライバシー

音声処理は **ASR → 言語モデル → TTS** です。メイン応答と直前の発言レビューは並行し、次の発言ヒントはメイン応答後に更新します。キャンセルとバージョン確認で古い応答の混入を防ぎます。

- マイクは音声入力に必要です。MiniMax ASR には今回の録音を送信します。ブラウザー認識の処理はブラウザーと認識サービスに依存します。
- カメラは任意のプレビューのみで、録画・画像送信をしません。閉じる・終了する・バックグラウンドに移ると解放します。
- 選択した文書は端末内で読み取り、画像理解には圧縮画像を送信します。採用したテキストは練習開始時にモデルへ送ります。
- 直接接続のキーは現在のタブの sessionStorage に保存します。安全な端末保管庫ではありません。プロキシのキーは無視対象の .env.local に置き、長期設定や書き出しに含めません。
- 履歴・保存表現・明示的に保存した練習テンプレートは現在のブラウザー内に保存します。アカウントやクラウド同期はなく、データを消す前に書き出してください。

## 開発と文書

アプリは easy-speak/ にあり、src/ に画面・Hook・基盤処理、server/ にローカルプロキシ、tests/ と docs/ にテストと仕様があります。既存ブラウザーデータの保存キーは互換性を維持します。

アプリのディレクトリで確認します。

```sh
npm run format:check
npm run lint
npm test
npm run build
npm run preview
```

ビルド先は easy-speak/dist です。preview はローカル確認用です。リポジトリのルートでソース ZIP を作成できます。

```powershell
.\Export-EasySpeak.ps1
```

release/easy-speak-source.zip に明示したファイルだけを収録し、既知のキーと一般的な秘密情報の形式を検査します。環境ファイル・依存関係・キャッシュ・ログ・ビルド成果物・ブラウザーの学習データは含めず、アップロードもしません。
